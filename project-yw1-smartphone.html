YO-KAI WATCH 1 Smartphone

About the game

YO-KAI WATCH 1 Smartphone is a remaster of the first YO-KAI WATCH game, that allow people to play the game for less than ten bucks. It's, for me, the most accessible version of the game because everyone have a smartphone in pocket; no more excuses to not buy the game, and even less since this french translation project exists!

The translation project

This translation project aims to port the old ones to this remaster. At first the YO-KAI WATCH 1 3DS one, and then those of the next games in french that also have french voices! I opted to create this project in line with the EnmaPatcher app to let anyone able to download it while owning a legal copy of the game, without real issues (excluding the way to get the DRM bypass file). Personally, I'm waiting for the "<PAGE>" tag to be added by the modding community of the game to let me able to resume this project better than ever. Once this one is finished, I'll also make my own done version of the Calimélo's project (YO-KAI WATCH 1 for Nintendo Switch in French).

My global advice

If you forget about the fact that PvP is gone, the game improves the original experience slightly. The navigation into menus and battles is pretty smooth (excluding the Yo-kai Wheel of the Nintendo 3DS, it's THE thing that cannot be replaced!). The only reproach that I can do is that the protagonist moves are sometimes difficult to control, but it's easy to gear. An other thing that I haven't understood is the fact that it wasn't even released in all languages that the game had on the Nintendo 3DS... In only one month, localization's done, everything already exists on the Nintendo 3DS version!
